# TG PROXY Ho1zze — Android

**TG PROXY Ho1zze** для Android — лёгкий локальный WebSocket MTProto-прокси для стабильной работы Telegram на Wi-Fi и мобильном интернете (4G/LTE).

## Возможности

- **Работа на Wi-Fi и мобильном интернете**: параллельный подбор быстрого маршрута к серверам Telegram (прямое подключение + Cloudflare Fallback по портам `443` и `80`, обход сбоев DNS через `1.1.1.1` / `8.8.8.8` DoH и Anycast IP).
- **Полная поддержка медиа**: загрузка сообщений, фото, видео и файлов (включая фрагментированные WebSocket-потоки и флаг `quick-ack`).
- **Уникальный ключ при первом запуске**: при первой установке автоматически генерируется новый 32-символьный секретный ключ.
- **Плитка в шторке быстрых настроек**: добавьте плитку **«TG PROXY»** в шторку Android — короткое нажатие включает/выключает прокси, удержание открывает приложение.
- **Настройки на лету**: изменение порта, генерация нового ключа (`↻`), переключение Cloudflare Fallback и **«Сбросить настройки»** применяются сразу, без ручного перезапуска прокси.
- **Фоновый сервис без усыпления**: Foreground Service (`specialUse`) с `WakeLock`, `WifiLock` и автообновлением пула соединений при переключении `Wi-Fi ↔ 4G`.

## Установка и подключение

1. Скачайте apk файл и установите приложение последней версии - **Перейти на [Release](https://github.com/Ho1zze/TG-PROXY-Ho1zze-Android/releases)**
2. Откройте приложение и нажмите **«▶ ЗАПУСТИТЬ ПРОКСИ»**.
3. Разрешите **уведомления** и **отключение оптимизации батареи** в появившихся системных окнах (это нужно, чтобы Android не выгружал прокси в фоне).
4. Нажмите **«Подключить в ТГ»** и подтвердите добавление прокси в Telegram.

> **Совет для Xiaomi (HyperOS / MIUI), Samsung, Realme:** если система всё равно ограничивает фоновую работу, откройте **Настройки телефона → Приложения → TG PROXY Ho1zze → Контроль активности** и выберите **«Нет ограничений»**.

## Вкладки приложения

- **Главная**: статус работы, индикатор Glyph, кнопка запуска/остановки, подключение в Telegram, статистика соединений/трафика (`RX`/`TX`) и таймер работы.
- **Настройки**: порт (по умолчанию `1443`), секретный ключ и кнопка генерации нового ключа, `Cloudflare Fallback`, автозапуск после перезагрузки телефона, отключение оптимизации батареи и кнопка **«Сбросить настройки»**.
- **Логи**: журнал подключений и сетевых событий в реальном времени.
